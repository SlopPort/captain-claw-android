Original recorder files are copied privately before the fixture.

**Save UI:** export/import failures now show actionable, distinct PL/EN instructions instead of untranslated internal exception messages. Vibration-save failure also has localized text. Technical causes remain in local logs. Validation, staging, existing saves and the late-Activity dialog guard are preserved.

## Performance evidence correction

The [debug39 sustained-run correction](UPDATE-0.4.39.md#2026-11-08-correction-sustained-observation-was-not-a-performance-pass) remains open performance work. An alive background process had been misreported as a sustained pass. The runner now checks active-foreground continuity and batch-duration coverage, and accepts an explicit minimum batch FPS. Host regression rejects background/pause, missing samples, short runs and a violated floor, while retaining skipped long loops separately.

Profiling adds overhead; this is not a new FPS result, causal proof of regression or an optimization gain. No resolution, image quality, physics step or AI rate was reduced.
