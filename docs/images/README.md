# Installation guide images

These PNGs show only this port's own Android interface on Huawei / Android 10,
version 0.4.31-dev. They were captured from app-owned views using
`InstallGuideTest` and visually inspected. No game artwork, game data,
notification contents or file-picker listings are included.

- `importer-en.png`: English first-import screen.
- `language-en.png`: app language selection dialog.

Images and test code were produced by OpenAI Codex (LLM). These original project
UI captures are supplied under the project GPL-3.0 terms. Android layout may
differ on another device. System installer and file-picker screens vary by ROM;
these images do not document all Android variants or a clean-computer setup.
